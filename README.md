# Date Code

This project contains a simple Jekyll site hosted on GitHub Pages.

## Live Page

You can view the live site here: **[https://emunozgutier.github.io/date-code/](https://emunozgutier.github.io/date-code/)**

## Local Development

If you want to test and develop the site locally, follow these steps:

1. Ensure you have [Ruby](https://www.ruby-lang.org/en/documentation/installation/) and [Bundler](https://bundler.io/) installed.
2. Install the dependencies:
   ```bash
   bundle install
   ```
3. Start the Jekyll server:
   ```bash
   bundle exec jekyll serve
   ```
4. Open your browser and go to `http://localhost:4000`.
